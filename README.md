## 核心功能

- **多题型混合组卷**：单词默写、整句默写、句子挖空、单项选择、行内填空、字母专项及英语作文可在同一张试卷中混排。
- **规范四线三格手写体**：内置多款标准英文衡水体与意大利斜体，范字基线精准对齐第三线，格线高度与粗细支持毫米级微调。
- **分栏排版自由度高**：支持分栏的题型可设置每行 1 至 5 题；作文保持整行排版。长句可自动整行跨列；支持 A4、B4、8K 纸张以及一页 1～3 份带裁切线排版。
- **本地题库管理**：支持 Excel / WPS 表格、CSV 文件和剪贴板粘贴导入，自动去重并按年级、单元分类；可批量加入试卷、调整分组和导出备份。
- **学生卷与教师答案版**：可生成学生练习卷与配套教师答案页，分页与末页规则经过浏览器 PDF 回归验证。
- **本地离线与数据留存**：构建产物按 HTML、CSS、JS、字体和图片分目录保存，无需联网即可双击入口页使用；草稿和题库保存在当前浏览器中。

## 📝 题型与功能亮点

### 1. 组卷与题型
- **单词默写**：支持中英对照、纯中文或纯英文输入，四线三格自动铺满列宽。
- **句子挖空**：支持在英文句子中点击单词切词胶囊设空，也支持使用方括号 `[word]` 批量标记；中文释义支持放置在句下、句末、句上或隐藏。
- **整句默写**：中文作为题干，根据句子长度智能分配 1~3 行四线三格供学生规范书写。
- **字母专项**：提供 26 个字母规范书写（大小写）、左右邻居默写、大小写互换等三年级专项题型，支持一键出卷。
- **选择与填空**：选择题默认生成 3 个选项（A、B、C），题号后自带答题括号 `（   ）`，选项内容简短时智能单行 3 列等分排版；填空题自动去除冗余提示文案，排版紧凑纯净。
- **英语作文**：支持设置作文标题、引导要求、指定行数与行高，超长题目仅在完整书写行间自然分页。
- **分栏隔断与排版**：支持插入分栏隔断，后续题目每行题数单行切换，各区段分栏互不干扰。
- **教师答案版**：可在学生卷后附加独立紧凑答案页，自动隐去书写格与学生信息，方便教师核对与批改。

### 2. 本地题库
- **年级与单元分组**：按年级与单元胶囊标签分类管理词汇，支持即时创建与修改分组。
- **表格与剪贴板极速导入**：支持上传不超过 10 MB 的 `.xlsx`、`.xls`、`.csv` 文件，更支持直接从 Excel 或 WPS 复制表格区域后按 `Ctrl + V` 粘贴解析入库。
- **自动查重与安全保存**：试卷题目可一键存入本地库，系统自动识别跳过已有重复词条。
- **备份与恢复**：可将当前试卷、卷面设置和题库导出为 JSON 备份。恢复前会显示影响范围；默认合并题库，也可明确选择覆盖恢复。恢复过程会校验设置和条目 ID，同 ID 的不同内容不会互相覆盖。

### 3. 版式与打印输出
- **每行 1 至 5 题自由分栏**：各题型可预设默认列数，也可在题目清单中单题覆盖；长句子超出列宽时智能整行通栏跨列。
- **标准规格纸张**：支持标准 A4（纵向/横向）、B4（257×364mm）以及中小学印刷常用 8K（260×370mm）大卷。
- **一页多份随测随裁**：支持一页排版 1 份、2 份或 3 份相同试题，各联之间自动绘制裁剪虚线，节省油墨与纸张。
- **末尾空白页控制**：打印样式与分页算法共同控制末页，并通过 A4、B4 PDF 页数回归检查。

## 🧭 教师出题指南

只需简单几步，即可快速生成一份标准的英语默写练习卷：

1. **进入题目录入**：打开网页后，在左侧导航点击「题目录入」。
2. **选择题型与输入内容**：
   - 录入单词：直接在输入框粘贴中英文（如 `apple 苹果`，每行一条）；
   - 录入挖空句子：输入英文句子后，直接在下方点击需要学生填写的单词胶囊（绿色高亮即为挖空位置），或使用 `ask [for help] 向老师求助` 文本格式；
   - 或点击「题库」，筛选已有单元词汇，勾选后点击「加入试卷」。
3. **点击添加到试卷**：点击绿色的「添加到试卷」按钮，题目将按顺序加入当前试卷。
4. **检查与调整题目**：切换至「试卷题目」，使用上移、下移按钮调整顺序；单击题目可修改内容，删除按钮只删除当前题目。
5. **设置纸张与版式**：在右侧「试卷排版」面板选择纸张（A4、B4、8K 或 A3）、方向和每页份数，并按题型设置每行题数、四线格高度与字号。
6. **核对右侧预览**：在右侧舞台实时查看学生卷排版效果与预计页数，支持缩放查看各联排版细节。
7. **打印或导出 PDF**：点击右上角「打印 / 导出 PDF」（或按快捷键 `Ctrl + P`）。

> [!TIP]
> **打印设置关键提示**：在浏览器的打印预览窗口中，请将 **页边距** 设为 **“无”**（页面内部已按物理毫米预留安全边距），并务必勾选 **“背景图形”**，以确保四线三格格线清晰呈现。

## 📋 输入与导入示例

### 1. 题目录入文本格式（每行一条）

```text
# 单词默写格式（支持空格、竖线或破折号分隔，支持带音标）
apple 苹果
classroom /'klɑːsruːm/ 教室
beautiful | 美丽的
hard-working - 工作努力的

# 句子挖空格式（使用方括号标记挖空单词）
ask [your teacher] for help | 向你的老师求助
I go to school [by bus]. | 我乘公共汽车去上学
```

### 2. Excel / WPS 表格导入格式

在「题库 → 导入词库」中，可直接上传表格文件，或复制多行单元格后粘贴：

| 年级与单元（第 1 列，可选） | 英文单词（必填） | 中文释义（建议填） | 说明 |
| :--- | :--- | :--- | :--- |
| 三年级上册 Unit 1 | ruler | 尺子 | 推荐 3 列标准格式：系统自动创建单元分组并归类 |
| 三年级上册 Unit 1 | pencil | 铅笔 | 自动识别并跳过表头行 |
| 四年级上册 Unit 2 | classroom | 教室 | 多单元混排时自动建组 |
| （留空） | book | 书本 | 2 列简易格式：归入当前选中的单元分组 |

## 🔒 数据与隐私安全

- **完全离线运行**：本工具所有逻辑均运行在本地浏览器中，不设云端数据库，出题数据不会上传至任何服务器。
- **数据本地留存**：词库、句库和自定义分组保存在 IndexedDB，当前试卷草稿与卷面设置保存在 localStorage；旧版自定义分组会在首次打开时自动迁移。
- **定期备份建议**：更换电脑或清理浏览器缓存前，建议点击页面右上角「导出备份」，保存当前试卷、卷面设置、词库和句库；题库面板中的「导出备份」仅导出本地题库，恢复时同样使用页面右上角「恢复备份」。

## ❓ 常见问题

**Q: 打印出来的四线三格没有线条？**  
A: 请在浏览器打印弹窗中勾选“背景图形”（部分浏览器称为“背景图案”或“打印背景”）。

**Q: 页面提示超出纸张容量怎么办？**  
A: 可在右侧「试卷排版」中尝试将每页份数由 3 份改为 2 份或 1 份，或微调每行题目列数，排版引擎会自动优化分页。

**Q: 软件可以在没有网络的教室电脑上使用吗？**  
A: 可以。请把编译生成的整个 `dist` 文件夹拷贝到 U 盘，并保持其中的 `css`、`js`、`fonts`、`img` 子目录不变；在现代浏览器（Edge、Chrome、360 极速浏览器等）中双击 `dist/index.html` 即可离线使用。在完整项目目录中双击根目录 `index.html`，也会自动进入该离线版本。

## 🛠️ 本地开发

本项目采用 Vue 3 + Naive UI + Vite 构建，仅面向参与维护的开发者：

```bash
# 安装依赖
npm install

# 启动本地开发热重载服务器
npm run dev

# 编译为可离线运行的多文件发行目录 (dist/)
npm run build

# 自动发现并执行 tests/test_*.js（当前 36 项）
npm run test:all
```
