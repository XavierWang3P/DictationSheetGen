# 代码与性能审计记录（2026-10-16）

> 当前发行格式为离线多文件 `dist/`，保留 `css`、`js`、`fonts`、`img` 子目录；仍支持双击 `dist/index.html`，但发布或复制时必须保留整个目录。

## 审计结论

本轮采用小步修改，没有对大型组件做机械拆分，也没有引入路由、国际化、TypeScript 或新的运行时依赖。主要边界保持为：Vue 组件负责交互，`stores` 保存共享状态，`core` 负责排版、导入和持久化，`question-types` 负责题型规范化，`testing` 只提供受查询参数保护的浏览器测试接口。

| 优先级 | 问题 | 证据位置 | 影响 | 建议方案 | 风险 | 是否实施 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 严重 | 复制单个 `dist/index.html` 时 OPPO Sans 丢失 | `src/styles/fonts.css` 原来引用 `/fonts/`；旧构建另有 `dist/fonts/` | 与单文件交付声明不符，离线电脑字体回退 | 改为相对路径的多文件发行，并要求完整复制 `dist/` 目录 | 发布时必须保持目录结构完整 | 是 |

## 性能复测

环境：Windows，Microsoft Edge 155.0.4283.45 无头模式，Node.js 24.19.0；直接打开 `file:///D:/DictationSheetGen/dist/index.html?__test=1`。每轮启动独立浏览器资料目录，测试 200 道单词题的真实输入、添加、列表排序和每行题数设置。数据取 3 次运行中位数；计时包含 Vue 更新和浏览器完成两帧渲染。

| 指标 | 修改前中位数 | 修改后中位数 | 变化 |
| :--- | ---: | ---: | ---: |
| 页面与内置字体就绪 | 1516.7 ms | 1077.5 ms | -29.0% |
| 200 题添加并完成预览渲染 | 721.7 ms | 627.6 ms | -13.0% |
| 列表题目下移并完成渲染 | 155.2 ms | 125.2 ms | -19.3% |
| 改为每行 5 题并完成预览渲染 | 169.1 ms | 167.7 ms | -0.8% |

修改后三次浏览器控制台错误均为 0，外部网络资源请求为 0，200 题生成 4 个预览页。启动指标现在显式等待 OPPO Sans 实际加载；修改前该字体检查失败，因此启动对比是偏保守的。

## 构建产物

| 当前发行内容 | 大小 |
| :--- | ---: |
| `dist/index.html` | 1,428 bytes |
| `dist/js/` | 1,201,056 bytes |
| `dist/css/` | 84,190 bytes |
| `dist/fonts/`（7 个字体文件） | 1,600,872 bytes |
| `dist/img/` | 299,347 bytes |
| `dist/` 合计 | 3,186,893 bytes（11 个文件） |

原单文件方案曾把字体和脚本全部内联，使 HTML 达到约 3.8 MB；现改为职责清晰的多文件目录，完整体积约 3.19 MB。所有引用均为相对路径，浏览器通过 `file://` 双击入口时无需服务器或外部网络。字体和四线三格资源未删减，打印精度保持不变。JS 相比前一次复测增加约 71 KB，原因是将 SheetJS 从 0.18.5 升级到官方 0.20.3；`npm audit --registry=https://registry.npmjs.org` 报告 0 项漏洞。

## 验证范围

- `npm run test:all` 自动发现 36 个测试文件，覆盖核心算法、旧数据迁移、IndexedDB、存储失败回滚、Excel/WPS、题库、全部现有题型、排序/复制/编辑/删除、1～5 题分栏、A4/B4/8K、多联、答案版、字体和打印 PDF。
- `test_production_isolation.js` 不使用测试全局状态，通过正式页面的输入框和按钮录入两道题，并确认正式构建没有隐藏测试控件。
- `test_restore_safety.js` 验证恢复前不修改数据、合并时大小写去重、同 ID 不同内容无损重建、事务落库、恶意字体设置无法注入页面，以及草稿/设置未知字段保留。
- `test_question_types_browser.js` 通过浏览器打印接口生成 A4、B4 PDF，核对页面数、答案隔离、裁切和末页。

浏览器自动化可以检查打印 DOM 和 PDF 页数，但不同打印机驱动仍可能改变硬件不可打印边距。实际纸张输出时仍建议使用“页边距：无”和“背景图形”，并先打印一页校准。
